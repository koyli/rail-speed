Trains: advertised origin departure to final arrival (public times), including stops. Routes: origin–destination pairs in either direction, ranked by their single fastest service — so the slowest route is the pair whose best train is slowest. Start-to-stop: fastest scheduled run between consecutive calls (working timetable, half-minutes). Calling at keeps only trains that stop at the station (anywhere en route); routes are then ranked using only those trains, as they are with the operator filter. Route miles follow the track network through every timing point; crow flies is the straight line between the end stations. ≈ marks distances partly estimated from straight lines.

Timetable: Network Rail open data. Station locations: NaPTAN (DfT).
